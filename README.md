# 🔐 Password Generator

A simple password generator built with **React**, **Tailwind CSS**, and **Vite**.  
Generates secure passwords with customizable length and character options.

## 🚀 Features
- Adjustable password length
- Toggle numbers
- Toggle special characters
- Instant generation
- Copy to clipboard

## 🛠️ Tech Stack
- React
- Tailwind CSS
- Vite

## 📦 Installation

```bash
git clone <your-repo-url>
cd <repo-name>
npm install
npm run dev
```

## ⚙️ Usage
- Select password length  
- Enable/disable numbers and special characters  
- Click generate  
- Copy password
